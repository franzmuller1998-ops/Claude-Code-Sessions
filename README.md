# Claude Code Sessions

A workspace for experimenting with Claude Code.

## What's here

This repository stores sessions, scripts, and notes from working with [Claude Code](https://claude.ai/code) — Anthropic's CLI for AI-assisted software engineering.

## Getting started

1. Install Claude Code: `npm install -g @anthropic-ai/claude-code`
2. Authenticate: `claude login`
3. Start a session: `claude`
