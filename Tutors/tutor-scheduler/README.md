# 📚 Репетитор — расписание и напоминания

Веб-приложение для частных репетиторов: ведите расписание занятий с учениками, а
напоминания автоматически приходят **и репетитору, и ученику** в Telegram.

- **Кабинет репетитора** (веб): ученики, разовые и повторяющиеся занятия, календарь.
- **Ученик** — без регистрации: переходит по персональной ссылке, жмёт «Старт» в боте
  и получает напоминания. Прямо в Telegram может подтвердить занятие или попросить
  перенос.
- **Напоминания** — за 24 часа и за 1 час до занятия (настраивается в
  `lib/constants.ts`), с учётом часовых поясов репетитора и ученика.

## Стек

Next.js 16 (App Router) · TypeScript · Tailwind CSS · Prisma + SQLite · grammY
(Telegram) · jose (сессии) · bcrypt.

## Быстрый старт

### 1. Зависимости

```bash
npm install
```

### 2. Создайте Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram → `/newbot`.
2. Задайте имя и username (должен заканчиваться на `bot`).
3. Скопируйте **токен** вида `123456:ABC-DEF...`.

### 3. Настройте окружение

Скопируйте `.env.example` в `.env` (или отредактируйте уже созданный `.env`) и
заполните:

```env
TELEGRAM_BOT_TOKEN="токен-от-BotFather"
NEXT_PUBLIC_BOT_USERNAME="username_бота_без_@"
AUTH_SECRET="длинная-случайная-строка"
CRON_SECRET="секрет-для-cron"
DATABASE_URL="file:./dev.db"
APP_URL="http://localhost:3000"
```

### 4. База данных

```bash
npx prisma migrate dev    # создаёт SQLite-базу и таблицы
npm run seed              # (необязательно) демо-репетитор и ученик
```

Демо-вход: `demo@example.com` / `password`.

### 5. Запуск (нужно два процесса)

```bash
npm run dev      # веб-кабинет на http://localhost:3000
npm run worker   # Telegram-бот (polling) + рассылка напоминаний каждые 30 c
```

## Как пользоваться

1. Зарегистрируйтесь на `/register` (или войдите демо-аккаунтом).
2. На главной нажмите **«Подключить Telegram»** и привяжите свой Telegram по ссылке —
   чтобы получать напоминания о занятиях.
3. В разделе **Ученики** добавьте ученика, откройте его карточку и отправьте ему
   **ссылку-приглашение**. Ученик откроет её и нажмёт «Старт».
4. В разделе **Расписание** создайте разовое или повторяющееся занятие.
5. Напоминания придут обоим за 24 ч и за 1 ч до занятия. Ученик в Telegram может
   нажать «✅ Подтверждаю» или «🔁 Перенести» — репетитору придёт уведомление.

## Архитектура напоминаний

- При создании занятия в таблице `Reminder` создаются записи на каждый офсет для
  репетитора и ученика (только будущие моменты).
- `npm run worker` каждые 30 секунд вызывает `processDueReminders()`
  ([lib/reminders.ts](lib/reminders.ts)) — отправляет наступившие напоминания и
  помечает их `sent`/`failed`. Повторно одно и то же напоминание не отправляется
  (статус + уникальный индекс `lessonId+recipient+remindAt`).
- Повторяющиеся занятия материализуются в конкретные `Lesson` на 8 недель вперёд.

## Деплой (прод)

- Поднимите Postgres (Neon/Supabase), смените `provider` на `postgresql` в
  [prisma/schema.prisma](prisma/schema.prisma) и `DATABASE_URL`.
- Вместо polling переключите бота на webhook: один раз вызовите
  `https://api.telegram.org/bot<TOKEN>/setWebhook?url=<APP_URL>/api/telegram`.
- Напоминания: [vercel.json](vercel.json) уже содержит Vercel Cron на
  `/api/cron/reminders` (раз в минуту). Роут защищён `CRON_SECRET`.

## Структура

```
app/
  (dashboard)/        кабинет репетитора (обзор, ученики, расписание)
  actions/            серверные экшены (auth, students, lessons, telegram)
  api/telegram/       webhook бота (прод)
  api/cron/reminders/ обработка напоминаний по расписанию (прод)
  login, register     авторизация
lib/
  bot.ts              Telegram-бот (grammY): привязка, кнопки
  reminders.ts        генерация/материализация/рассылка напоминаний
  time.ts             часовые пояса (UTC ↔ локальное время)
  auth.ts             сессии (JWT-cookie) и пароли
  prisma.ts, constants.ts, tokens.ts
prisma/schema.prisma  модель данных
scripts/worker.ts     dev-процесс: бот + цикл напоминаний
```
